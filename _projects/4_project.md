This project gathers exploratory work that transfers aerospace-style modeling and optimization methods into human-centered systems. The aim is to describe complex movement, training, and decision processes with enough structure to support analysis, comparison, and eventual simulation.

The current focus is on three connected questions:

- How can motion and embodied skill be represented as a dynamic system?
- Which variables are useful when comparing technique, efficiency, and adaptation?
- How can engineering modeling methods help bridge physical, cognitive, and social dimensions of human performance?

The project is intentionally interdisciplinary. It connects multibody dynamics, biomechanics, knowledge organization, and practical optimization, with applications that may include martial arts movement, rehabilitation-oriented motion analysis, and broader medical-human system design.
